Quick Setup

Three simple steps to get your self-hosted AI-powered work logging system running.

1

Install CLI

brew tap k61b/tap
brew install logswise-cli

Or download the latest release from GitHub for your platform.

2

Setup AI Backend

curl -fsSL https://ollama.ai/install.sh | sh
ollama serve
ollama pull llama3

Install Ollama and pull your preferred model for AI features.

3

Configure & Run

logswise setup --express
logswise init
logswise

Quick setup with your Supabase credentials, then start logging!
